# رحلة — الهوية الرقمية التنبؤية للمسافر

نموذج تفاعلي (MVP) لهاكثون تجربة المسافر — وزارة الداخلية.

## كيف تشغّله على GitHub Pages

1. أنشئ مستودع (repository) جديد على GitHub، أو استخدم مستودع موجود.
2. ارفع ملف `index.html` هذا لجذر المستودع (أو داخل مجلد باسم `docs`).
3. من إعدادات المستودع: **Settings → Pages**.
4. تحت **Branch**، اختر الفرع (عادة `main`) والمجلد (`/root` أو `/docs` حسب مكان الملف) ثم احفظ.
5. بعد دقيقة أو دقيقتين، GitHub يعطيك رابطًا شكله:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
6. افتح الرابط — النموذج يشتغل مباشرة في المتصفح، بدون أي خطوة بناء (build).

## ملاحظة تقنية
الملف مستقل بالكامل: يحمّل React و Babel من CDN ويترجم الكود مباشرة في المتصفح،
فما تحتاج Node.js ولا npm ولا أي إعداد إضافي — فقط ارفع وفعّل Pages.
